# Block Shelf – Privacy Policy

Privacy policy for the Block Shelf mobile game, served with GitHub Pages at
https://shazaibsarwar.github.io/blockshelf-privacy/

Contact: info.shasar@gmail.com

## Publishing
1. Create a GitHub repository named `blockshelf-privacy`, then from this folder:
   `git init -b main && git add -A && git commit -m "Block Shelf privacy policy" && git remote add origin https://github.com/ShazaibSarwar/blockshelf-privacy.git && git push -u origin main`
2. Settings → Pages → Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`
   (or use the included GitHub Actions workflow).
3. Paste the page URL into Play Console → App content → Privacy policy.
